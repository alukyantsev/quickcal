# Triage Labels

| Роль | Статус в локальном трекере | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Задачу нужно оценить |
| `needs-info` | `needs-info` | Нужна дополнительная информация |
| `ready-for-agent` | `ready-for-agent` | Задача полностью определена и готова к реализации |
| `ready-for-human` | `ready-for-human` | Нужна реализация человеком |
| `wontfix` | `wontfix` | Задача не будет выполняться |
