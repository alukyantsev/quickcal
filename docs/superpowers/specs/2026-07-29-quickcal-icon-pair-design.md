# QuickCal: связанная пара иконок

Дата: 2026-07-29  
Ветка: `feature/quickcal-calendar-enhancements`

## Цель

Заменить текущую иконку-календарную сетку на связанную пару:

- нативная монохромная иконка в menu bar;
- цветная macOS-иконка приложения в Finder и `/Applications`.

Обе версии должны одинаково передавать идею QuickCal: быстрый доступ к
календарю и текущему времени.

## Выбранное направление

Пользователь выбрал вариант A — **«Календарь + время»**.

Основной знак состоит из календаря и круглого clock badge в правом нижнем
углу. Текст и буква `Q` в иконках не используются.

## Иконка menu bar

Используется нативный SF Symbol:

```text
calendar.badge.clock
```

Требования:

- `NSStatusItem` сохраняется, чтобы macOS не нормализовала символ до прежних
  12 pt;
- режим template image — монохромная иконка автоматически адаптируется к
  светлой и тёмной темам;
- исходная конфигурация: 18 pt, weight `medium`;
- после установки размер проверяется по фактическому screenshot;
- целевая оптическая высота — не менее 95% от 17-point reference ChatGPT;
- символ не должен обрезаться внутри системной высоты menu bar;
- accessibility label остаётся `QuickCal`.

## Иконка приложения

Иконка Finder создаётся как статичная цветная macOS-иконка:

- стандартный squircle без дополнительной внешней рамки;
- сине-голубой градиент от светлого верхнего левого угла к насыщенному
  синему нижнему правому;
- белый календарь;
- белый круглый clock badge в правом нижнем углу;
- синяя стрелка часов внутри badge;
- мягкий внутренний свет и системная глубина без фотореализма;
- без текста, номера дня, букв и мелких декоративных деталей.

Пользовательский accent color macOS продолжает применяться к интерактивным
элементам приложения. Finder-иконка остаётся статично синей, поскольку macOS
не перекрашивает app icon выбранным accent color.

## Корреляция двух версий

Версии используют:

- одинаковую композицию «календарь + часы»;
- badge одинакового относительного размера;
- одинаковое положение badge;
- сопоставимые пропорции основного календаря.

Различается только способ отрисовки:

- menu bar — системный контурный template symbol;
- Finder — цветная объёмная иконка.

## Ресурсы приложения

Мастер создаётся в размере 1024×1024 px. Из него формируются macOS icon
representations:

```text
16×16
16×16@2x
32×32
32×32@2x
128×128
128×128@2x
256×256
256×256@2x
512×512
512×512@2x
```

Результат упаковывается в `QuickCal.icns`, копируется в
`QuickCal.app/Contents/Resources` и подключается через `CFBundleIconFile` в
`Support/Info.plist`.

Сборочный скрипт должен завершаться ошибкой, если файл иконки отсутствует или
не попал в bundle.

## Проверка

После реализации проверяются:

1. `calendar.badge.clock` отображается в menu bar без clipping.
2. Runtime-тест оптического размера проходит относительно 17-point reference.
3. Popover по-прежнему открывается и меняет ширину 342→310 pt.
4. `QuickCal.icns` присутствует в собранном bundle.
5. `CFBundleIconFile` указывает на существующий ресурс.
6. Finder показывает новую иконку установленной `/Applications/QuickCal.app`.
7. Приложение остаётся arm64 и проходит `codesign --verify`.
8. Полный набор текущих тестов QuickCal остаётся зелёным.

## Вне scope

- динамическая смена Finder-иконки по accent color;
- разные иконки для светлой и тёмной темы Finder;
- отображение текущего числа месяца внутри app icon;
- публикация ресурсов в App Store.
