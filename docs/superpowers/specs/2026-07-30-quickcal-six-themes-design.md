# QuickCal: шесть тем оформления

Дата: 2026-07-30  
Ветка: `codex/quickcal-six-themes`

## Цель

Перенести в QuickCal утверждённую визуальную систему из шести тем, сохранив
существующую функциональность календаря:

- System Light;
- System Dark;
- Swiss Home Light;
- Swiss Home Dark;
- Color Light;
- Color Dark.

Три концепции используют одну композицию и одинаковое поведение. Light/Dark
варианты каждой концепции отличаются цветовыми токенами и appearance, но не
набором функций.

## Выбор темы

При отсутствии сохранённого ручного выбора QuickCal следует appearance macOS:

- Light → `System Light`;
- Dark → `System Dark`.

Кнопка с SF Symbol `paintpalette` переключает конкретные темы по кругу:

```text
System Light
→ System Dark
→ Swiss Home Light
→ Swiss Home Dark
→ Color Light
→ Color Dark
→ System Light
```

Первое ручное переключение создаёт сохранённый выбор. После этого изменение
appearance macOS не переопределяет тему приложения. Выбранная тема хранится в
`UserDefaults` под версионным ключом `quickCalTheme.v1`.

Отдельная команда возврата в автоматический системный режим в эту итерацию не
входит.

## Общая композиция

Popover сохраняет все существующие функции, но использует единую композицию:

1. локализованная полная дата;
2. карточка календаря:
   - предыдущий месяц;
   - заголовок месяца;
   - единственная видимая кнопка `Сегодня`;
   - следующий месяц;
   - дни, номера недель и выбранные даты;
3. тихий служебный футер:
   - номера недель;
   - автозапуск;
   - следующая тема;
   - выход.

Надпись `Сегодня` не дублируется рядом с полной датой. Кнопки темы и выхода
остаются icon-only, получают локализованные help/accessibility labels и
30×30 pt hit area.

При включённых номерах недель ширина popover равна 360 pt, при выключенных —
328 pt. Скрытие номеров недель по-прежнему уменьшает окно без пустой колонки.

## System

Нативная системная концепция.

- Light background: градиент `#F8FAFF → #E4E9F4`.
- Dark background: `#15181D`.
- Радиус внешней поверхности: 24 pt.
- Календарная карточка: 18 pt.
- Today: системно-синий (`#247BF2` / `#628CFF`).
- Выходные: `#DF5964` / `#FF7079`.
- Выбор: `#48A66F` / `#258E6B`.
- Типографика: системная San Francisco.

## Swiss Home

Строгая типографическая концепция.

- Light background: `#FBFAF6`.
- Dark background: `#181916`.
- Верхний коралловый маркер: 4 pt, `#DF6660`.
- Радиус внешней поверхности: 10 pt.
- Календарная карточка не отделяется заливкой от фона.
- Заголовки даты и месяца выводятся uppercase.
- Контролы и выделения используют прямоугольную геометрию с радиусом 4–5 pt.
- Today: `#30312F` / `#F0EFE9`.
- Выходные: `#D75555` / `#EF7770`.
- Выбор: `#83996F` / `#748C65`.

## Color

Выразительная цветная концепция.

- Light background: `#F8F1EC`.
- Dark background: тёмный сине-фиолетовый градиент с бирюзовым и розовым
  свечением.
- Радиус внешней поверхности: 29 pt.
- Полная дата находится в отдельной мягкой плашке.
- Радиус календарной карточки: 20 pt.
- Today: `#846FE3` / `#73A8FF`.
- Выходные: `#D45F70` / `#FF9FBE`.
- Выбор: `#58A892` / `#48BCA5`.

## Состояния и приоритеты

В каждой теме сохраняется существующий приоритет:

1. текущий день;
2. сохранённый выбранный диапазон;
3. нерабочий день;
4. обычный день вне/внутри месяца.

Hover не перекрывает Today и selected. Анимации используют существующее
системное значение Reduce Motion.

## Accessibility и локализация

- Новая строка `Следующая тема` / `Next theme` добавляется в ресурсы
  `QuickCalKit`.
- `paintpalette` используется и как help, и как accessibility label.
- `power` сохраняет локализованную подпись выхода.
- Тема не передаётся только цветом: назначение кнопки доступно VoiceOver.
- Светлая/тёмная семантика каждой темы применяется к SwiftUI и `NSPopover`,
  поэтому системные checkbox и focus-состояния имеют правильный контраст.

## Что не входит

- отдельное окно настроек;
- названия тем в popover;
- выпадающее меню выбора темы;
- синхронизация темы через iCloud;
- изменение логики календаря, производственного календаря, выбранных дат или
  автозапуска;
- автоматический возврат к системной теме после ручного выбора.

## Проверка

### Автоматическая

- порядок всех шести тем и циклический переход;
- System Light/System Dark при отсутствии сохранённого выбора;
- сохранение ручной темы и её приоритет над последующими изменениями macOS;
- fallback на системную тему при повреждённом значении `UserDefaults`;
- соответствие Light/Dark каждой темы appearance `NSPopover`;
- локализация `Следующая тема` / `Next theme`;
- полный `./Scripts/test.sh`;
- production-сборка `./Scripts/build-app.sh`.

### Runtime

- по одному screenshot каждой из шести тем;
- единственная видимая надпись `Сегодня`;
- компактный служебный футер;
- понятная иконка-палитра;
- полный ручной цикл из шести кликов;
- корректные цвета Today, выходных, выбранного диапазона и соседнего месяца;
- изменение ширины при скрытии номеров недель;
- сохранение темы после quit/relaunch.
