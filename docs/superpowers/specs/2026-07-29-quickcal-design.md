# QuickCal — дизайн приложения

## Цель

QuickCal — компактный локальный календарь для строки меню macOS. Приложение
должно быстро показывать календарь без открытия отдельного окна и не отображаться
в Dock.

## Ограничения

- Целевая платформа: macOS 14 или новее на Apple Silicon (`arm64`), включая
  процессоры Apple M4.
- Распространение: только локальное, без Mac App Store и обязательной
  notarization.
- Сборка должна работать через установленный Swift toolchain без полного Xcode.
- Интерфейс должен использовать системные цвета, типографику и поведение macOS.
- В приложении нет событий, напоминаний, синхронизации и сетевых функций.

## Пользовательский интерфейс

### Строка меню

- QuickCal работает как menu bar-only приложение.
- В строке меню отображается монохромная template-иконка календаря. macOS сама
  подбирает белый или чёрный цвет в зависимости от оформления строки меню.
- Нажатие на иконку открывает компактное popover-окно; повторное нажатие или
  клик вне окна закрывает его.
- Иконка приложения не отображается в Dock.

### Popover календаря

Окно повторяет структуру приложенного макета:

1. Полная текущая дата в верхней строке.
2. Разделитель.
3. Название просматриваемого месяца и года по центру.
4. Кнопки перехода к предыдущему и следующему месяцу.
5. Заголовки дней недели.
6. Сетка календаря из полных недель.
7. Разделитель и настройки.
8. Команда «Выйти из QuickCal».

Сегодняшний день выделяется кругом пользовательского accent color macOS.
При стандартном синем accent color круг будет синим. Дни соседних месяцев,
попавшие в сетку, отображаются приглушённо. Локаль, названия месяцев и дней,
первый день недели, цифры и формат полной даты берутся из системных настроек
macOS.

Навигация меняет только просматриваемый месяц. При новом запуске QuickCal
открывает текущий месяц. Выбор отдельных дат не предусмотрен.

### Настройки

В popover расположены два переключателя:

- «Показывать номера недель» — показывает или скрывает отдельную колонку с
  номерами недель справа. Это согласованная трактовка пункта с макета.
- «Запускать при входе» — регистрирует или удаляет QuickCal как login item
  текущего пользователя.

Настройка показа номеров недель сохраняется локально между запусками.
Состояние автозапуска читается из системного API macOS, а не дублируется в
пользовательских настройках.

## Архитектура

### Технологии

- Swift 6.
- SwiftUI для интерфейса.
- `MenuBarExtra` в оконном стиле для menu bar-иконки и popover.
- Foundation `Calendar`, `Date` и `Locale` для календарных вычислений.
- `ServiceManagement.SMAppService.mainApp` для запуска при входе.
- `UserDefaults` через `@AppStorage` для показа номеров недель.

Приложение не использует сторонние библиотеки и не требует сетевого доступа.

### Компоненты

- `QuickCalApp` — жизненный цикл приложения и `MenuBarExtra`.
- `CalendarPopoverView` — композиция popover, навигация и команды.
- `CalendarGridView` — визуальная сетка дней и необязательная колонка недель.
- `CalendarMonth` — чистая модель, формирующая полные недели для выбранного
  месяца с учётом системного календаря и первого дня недели.
- `LaunchAtLoginController` — чтение статуса, регистрация и удаление login item,
  а также пользовательская ошибка при неудаче.

Модель календаря не зависит от SwiftUI. Это позволяет проверить календарные
границы обычными unit-тестами.

## Поток данных

1. При запуске приложения просматриваемый месяц инициализируется текущим.
   Последующая навигация сохраняется до завершения процесса QuickCal.
2. `CalendarMonth` получает выбранный месяц и системный `Calendar`, затем
   возвращает строки полных недель.
3. Стрелки меняют месяц на `-1` или `+1`, после чего сетка пересчитывается.
4. Переключатель номеров недель обновляет `@AppStorage`; значение автоматически
   восстанавливается при следующем запуске.
5. Переключатель автозапуска вызывает `SMAppService`. После операции интерфейс
   повторно читает реальный системный статус.
6. «Выйти из QuickCal» завершает приложение через `NSApplication`.

## Обработка ошибок

- Ошибка регистрации или удаления автозапуска не меняет переключатель на
  недостоверное состояние.
- Краткое локализованное сообщение об ошибке показывается рядом с настройкой
  автозапуска.
- Календарные вычисления не используют принудительное извлечение optional
  значений. При невозможной календарной операции интерфейс возвращается к
  текущему месяцу, не завершая приложение аварийно.
- Сетевых и фоновых ошибок нет, поскольку приложение полностью локальное.

## Сборка и установка

- Репозиторий содержит Swift Package, исходники, тесты и воспроизводимый скрипт
  сборки app bundle.
- Release-бинарник собирается только для `arm64`.
- Скрипт формирует `QuickCal.app`, добавляет `Info.plist`, ресурсы и выполняет
  локальную ad hoc-подпись.
- Готовый bundle можно скопировать в `/Applications` обычным Finder или
  командой установки. Для надёжной работы системного login item QuickCal
  запускается из `/Applications`.

## Проверки

### Автоматические

- Unit-тесты для обычного месяца, перехода года, февраля високосного года,
  разных первых дней недели, сегодняшней даты и номеров недель.
- Канонический прогон `./Scripts/test.sh`: regression-тест сборочного скрипта
  и фактическое выполнение Apple Swift Testing suite с ненулевым числом тестов
  и нулевыми `errors`/`failures` в xUnit.
- Release-сборка.
- Проверка `Info.plist`.
- Проверка, что Mach-O бинарник имеет архитектуру `arm64`.
- Проверка целостности ad hoc-подписи через `codesign`.

### Runtime

- QuickCal запускается без появления в Dock.
- В строке меню появляется системная иконка календаря.
- Popover открывается и закрывается по нажатию.
- Месяцы переключаются в обе стороны, включая границу года.
- Сегодняшний день выделен пользовательским accent color macOS.
- Колонка номеров недель включается и выключается, настройка переживает
  перезапуск.
- Переключатель login item регистрирует и удаляет QuickCal, а его состояние
  соответствует системному.
- Команда выхода завершает процесс.

## Критерии приёмки

- Пользователь получает готовый `QuickCal.app`, который запускается локально на
  Mac с M4.
- QuickCal работает только в строке меню и визуально соответствует системному
  стилю macOS и структуре приложенного макета.
- Календарь показывает текущую дату, позволяет листать месяцы и корректно
  строит сетку по системной локали.
- Номера недель можно показать или скрыть.
- Автозапуск можно включить и выключить из popover.
- Из popover можно завершить приложение.
- Все автоматические проверки проходят, а runtime-пункты проверены на текущем
  Mac либо явно отмечены как непроверенные с причиной.

## Не входит в scope

- События, встречи, напоминания и редактирование дат.
- Интеграция с Apple Calendar, iCloud или сторонними календарями.
- Уведомления и сетевой доступ.
- Версия для Intel Mac.
- Публикация, Developer ID-подпись и notarization.
- Отдельное окно настроек или иконка в Dock.
