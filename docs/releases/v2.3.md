# QuickCal 2.3 — Спринты в календаре

Дата релиза: 12 августа 2026

## Новое

- В дополнительных настройках появилась локальная настройка расписания спринтов; по умолчанию функция выключена.
- Можно задать точную дату и номер первого спринта, а также базовую длительность 14 календарных дней.
- В календаре рядом с номерами недель отображается компактная колонка спринтов: один номер, переход между номерами или тире для паузы.
- Для отдельного спринта доступны длительности 7, 14, 21 дней и произвольное положительное число дней.
- Паузы исключают даты из расписания, завершают предыдущий спринт и запускают следующий с новым номером после паузы.
- Паузы отображаются в настройках и могут быть удалены; при увеличении длительности спринта перекрытая часть паузы снова становится частью спринта.
- Дни текущего спринта получают мягкую заливку без конкуренции с сегодняшним днём, пользовательским выбором и выходными; состояния доступны VoiceOver.
- Настройки спринтов скрываются при выключенном `Show Sprints`, а окно настроек прокручивается при большом количестве параметров.
- Нажатие на номер спринта открывает его редактор; поле длительности показывает фактическую длину с учётом пауз.
- Колонка спринтов выровнена с номерами недель, а ширина календаря учитывает только фактически необходимую ширину сетки.
