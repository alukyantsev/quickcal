# QuickCal 2.1.1 — Точные изменения котировок вне торгов

Дата релиза: 9 августа 2026

## Исправление

- Для акций и фьючерсов, когда MOEX ISS явно сообщает `NUMTRADES = 0`, QuickCal показывает фактическое отсутствие движения: `0` и `0%`.
- Если сделки были, дневное изменение берётся из полей MOEX ISS даже при `LASTCHANGE = 0`: это поле относится к последней сделке и не является признаком отсутствия торгов за сессию.
- Для такого случая приложение больше не вычисляет изменение как разницу между последней ценой и `PREVPRICE`: это поле могло относиться к предыдущей сессии и создавать ложное движение.
- Если процентное поле дневного изменения отсутствует, процент рассчитывается только на основе фактического поля `LASTCHANGE` — без обращения к `PREVPRICE`.

## Изменения для разработки

- Версия приложения: `2.1.1` (build `7`).
- Добавлены регрессионные тесты MOEX ISS: `NUMTRADES = 0` обнуляет абсолютное и процентное изменения, а ненулевое число сделок сохраняет фактическое дневное изменение.
- Полный тестовый прогон: 125 тестов успешно.

## Требования

- macOS 14 или новее;
- Apple Silicon (`arm64`).

## Установка

Скачайте `QuickCal-v2.1.1-arm64.zip`, распакуйте `QuickCal.app`, перенесите его в `/Applications` и откройте приложение.
