# QuickCal 2.1.2 — Погода и IMOEX в строке меню

Дата релиза: 11 августа 2026

## Новое

- В настройках добавлен переключатель «Показывать информацию в строке меню».
- При включении QuickCal показывает компактный статус: текущую температуру в °C и значение индекса IMOEX.
- Если доступен только один источник, строка меню продолжает показывать доступное значение.
- Кешированные данные сохраняются, но отображаются приглушённо; VoiceOver и tooltip сообщают время их обновления.
- Пока данные загружаются или недоступны, QuickCal сохраняет обычную иконку вместо placeholders.

## Изменения для разработки

- Версия приложения: `2.1.2` (build `9`).
- Подробный status item остаётся одной кнопкой: нажатие открывает обычный календарный popover.
- Добавлены тесты хранения настройки, состояний представления, accessibility и AppKit-рендера.

## Требования

- macOS 14 или новее;
- Apple Silicon (`arm64`).

## Установка

Скачайте `QuickCal-v2.1.2-arm64.zip`, распакуйте `QuickCal.app`, перенесите его в `/Applications` и откройте приложение.
