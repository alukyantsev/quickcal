# 02 — Исключения длины, паузы и быстрый редактор

**What to build:** пользователь может менять длину отдельного спринта через пресеты 7/14/21 или произвольное число дней, добавлять периоды без спринтов и быстро править выбранный спринт из его номера; изменение прошлого расписания требует предупреждения и согласованно пересчитывает будущее.

**Blocked by:** 01 — Базовое расписание и отображение спринтов.

**Status:** done

- [x] Отдельный спринт поддерживает пресеты и произвольную положительную длину, а строка недели честно показывает смену номеров внутри неё.
- [x] Пауза исключает её даты, завершает предыдущий спринт и начинает следующий с новым номером после паузы.
- [x] Редактор из меню и быстрый редактор из номера спринта не перегружают основной календарь; исторические изменения требуют подтверждения.
- [x] Недопустимые правила отклоняются, а исключения, паузы, пересчёт и accessibility покрыты тестами.
