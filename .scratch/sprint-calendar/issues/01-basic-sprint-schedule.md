# 01 — Базовое расписание и отображение спринтов

**What to build:** пользователь может включить спринты, задать точную дату и номер первого спринта, увидеть двухнедельное расписание в компактной колонке календаря и мягкую заливку текущего спринта; новая функция и календарь по умолчанию остаются выключенными и неизменёнными.

**Blocked by:** None — can start immediately.

**Status:** done

- [ ] Первичная настройка включает функцию только после явного действия пользователя и локально сохраняет базовое расписание с 14 календарными днями.
- [ ] Календарь показывает номера спринтов по неделям, в том числе корректно на границе года, и отдельную заливку дней текущего спринта.
- [ ] Новые состояния локализованы, доступны через VoiceOver и не перекрывают семантику Today, выбранных дат и выходных.
- [ ] Доменное расписание, хранилище и календарное представление покрыты детерминированными тестами.
