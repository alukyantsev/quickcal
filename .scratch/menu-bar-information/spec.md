# Подробная информация в строке меню

**Status:** ready-for-agent

## Problem Statement

QuickCal показывает в строке меню только статичную иконку календаря. Пользователь не может одним взглядом увидеть температуру и значение индекса IMOEX, хотя приложение уже получает и кеширует эти данные.

## Solution

Добавить выключенную по умолчанию настройку «Показывать информацию в строке меню». Когда она включена, status item использует композицию макета 3: пиктограмма погоды, температура в градусах Цельсия, разделитель, подпись IMOEX и его значение. Нажатие на весь item по-прежнему открывает календарный popover.

## User Stories

1. Как пользователь QuickCal, я хочу включить подробную информацию в строке меню, чтобы видеть погоду и IMOEX без открытия popover.
2. Как новый пользователь, я хочу, чтобы подробный режим был выключен по умолчанию, чтобы привычная иконка QuickCal не менялась без моего выбора.
3. Как пользователь, я хочу видеть температуру в °C в компактном формате, чтобы быстро оценивать погоду.
4. Как пользователь, я хочу видеть текущее значение IMOEX, чтобы быстро оценивать российский рынок.
5. Как пользователь с отключённой погодой, я хочу продолжать видеть доступный IMOEX, а не терять всю информацию.
6. Как пользователь с отключёнными котировками, я хочу продолжать видеть доступную температуру.
7. Как пользователь при первом запуске или обновлении, я хочу видеть обычную иконку, пока данные не получены, чтобы не принимать placeholder за факт.
8. Как пользователь при сетевой ошибке, я хочу видеть валидные кешированные значения приглушёнными, чтобы отличать их от свежих.
9. Как пользователь VoiceOver, я хочу получить объединённое локализованное описание status item с состоянием свежести данных.
10. Как пользователь, я хочу, чтобы клик по расширенному item открывал тот же календарный popover, без новых действий по отдельным данным.

## Implementation Decisions

- Настройка хранится локально и переживает перезапуск; её default — `false`.
- Status item сохраняет variable width и template-отображение системной пиктограммы; значения выводятся нативным текстом, не растровой иконкой.
- Формат подробного режима: weather icon + `+18°` + разделитель + `IMOEX 2740`; дневное изменение индекса не выводится.
- Температура берётся только из текущего доступного weather presentation state; IMOEX — только из доступного snapshot соответствующего ticker.
- При загрузке или полной недоступности обоих источников status item возвращается к обычной QuickCal-иконке. Если доступен один источник, выводится только его группа.
- Состояние stale сохраняет последнее валидное значение, использует вторичный цвет и сообщает время в tooltip/accessibility. Свежие данные используют primary color.
- Композиция остаётся одной кнопкой с существующим target/action и открывает текущий popover.
- Переключатель находится в существующей панели настроек рядом с видимостью погоды и котировок; русская и английская локализации добавляются одновременно.

## Testing Decisions

- Тестировать публичное представление menu bar из сочетаний weather и quote states: fresh, stale, loading, unavailable и частично доступные данные.
- Проверить default и persistence настройки через изолированный UserDefaults fixture, по образцу weather/market settings tests.
- Проверить локализованные настройки и accessibility/tooltip текст без привязки тестов к пиксельной реализации AppKit.
- Добавить runtime-проверку, что item расширяется в подробном режиме и сохраняет одно действие открытия popover.

## Out of Scope

- Дневное изменение IMOEX, цветовые индикаторы роста/падения и выбор других тикеров для menu bar.
- Отдельные клики по температуре, IMOEX, настройка ширины либо новые источники данных.
- Изменение 30-минутного lifecycle погоды и котировок.

## Further Notes

Макет 3 утверждён как исходная композиция. При отсутствии обоих источников пользователь всегда видит текущую иконку QuickCal, без `—` и других placeholders.
