# 01 — Подробная информация в строке меню

**What to build:** Пользователь может включить в настройках подробный status item QuickCal. Он показывает доступные температуру и IMOEX в композиции макета 3, сохраняет выбор между запусками и открывает тот же календарный popover.

**Blocked by:** None — can start immediately.

**Status:** done

- [x] Настройка выключена по умолчанию, локализована и сохраняется между запусками.
- [x] Подробный item показывает свежие и stale данные корректно, без placeholders при загрузке.
- [x] При недоступности одного источника виден другой; при отсутствии обоих остаётся обычная иконка QuickCal.
- [x] Клик и accessibility status item сохраняют существующее поведение и описывают отображаемые данные.
- [x] Покрыты unit и релевантные runtime-проверки.
