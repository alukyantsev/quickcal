# 06 — Автогеолокация и постраничная навигация погоды

**Status:** done

## Что исправлено

- После системного разрешения automatic location сразу получает город, сохраняет его и запрашивает прогноз.
- При выключении automatic mode последняя автоматически определённая локация остаётся активной до ручного выбора нового города.
- Стрелки и колесо мыши листают прогноз страницами по четыре периода.
- Provider запрашивает следующие 48 часов через `forecast_hours`, поэтому четыре периода доступны и для агрегации 8/12 часов независимо от времени суток.
