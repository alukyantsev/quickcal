# 02 — Отсчёт до отпуска

**What to build:** QuickCal группирует последовательные выбранные даты в отпуска и показывает под сеткой ближайший актуальный или будущий отпуск с корректным отсчётом и локализованной датой. Прошедшие даты остаются сохранёнными, но не создают строку.

**Blocked by:** 01 — Расширенная календарная сетка.

**Status:** done

- [x] Последовательные даты, в том числе через недели и месяцы, образуют один отпуск; разрывы создают отдельные отпуска.
- [x] Строка корректно обрабатывает будущий, текущий, последний и однодневный сегодняшний отпуск, исключая сегодняшний день из остатка.
- [x] Русская и английская версии используют правильные формы числа и форматы диапазонов внутри месяца и между месяцами.
- [x] Строка не отображается, если выбранные даты есть только в прошлом; логика и локализация покрыты тестами.
