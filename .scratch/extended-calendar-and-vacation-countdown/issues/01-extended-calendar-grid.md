# 01 — Расширенная календарная сетка

**What to build:** QuickCal всегда показывает выбранный месяц вместе с полной неделей до существующей сетки и полной неделей после неё. Все показанные даты остаются интерактивными, получают производственный календарь и номера недель, а месяц в заголовке не меняется при клике по соседнему месяцу.

**Blocked by:** None — can start immediately.

**Status:** done

- [ ] Сетка включает граничные недели месяца и по одной полной дополнительной неделе сверху и снизу, начиная недели по понедельникам.
- [ ] Производственный календарь охватывает полный показанный диапазон, включая переход через год.
- [ ] Выделения соединяются через границы строк и месяцев, а поповер показывает сетку полностью без прокрутки.
- [ ] Поведение защищено тестами календарной модели, сегментов выделения и загрузки производственного календаря.
